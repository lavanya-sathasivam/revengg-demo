INTEGRATION PIPELINE (verified)
--------------------------------

UI change-type dropdown
  --> POST /impact with change_type field
  --> API route: change_type=req.change_type threaded to analyze_change()
  --> analyze_change(): change_type passed to counterfactual(change_type=...)
  --> counterfactual(): dispatched to correct typed method
  --> Method produces rows + notes with explicit evidence provenance
  --> Status: supported/partial/unsupported based on graph state
